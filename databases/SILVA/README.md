# SILVA reference database

This directory is intended to contain the SILVA v138.2 reference files required for taxonomic assignment.

The following files are expected by the analysis pipeline:

- `silva_nr99_v138.2_toGenus_trainset.fa.gz`
- `silva_v138.2_assignSpecies.fa.gz`

The SILVA reference files are not distributed with this repository and must be obtained separately before running the pipeline.
